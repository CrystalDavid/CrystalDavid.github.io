# 论文列表的内容依据与公开范围

旧网站、三篇论文原件与 CV 均作为只读来源。标题、作者顺序和展示图片依据用户提供的 PDF，投稿状态依据 CV 第 1 页；没有把投稿中稿件写成已录用，未新增未提供的代码链接，CV 本身不公开。

当前仅 ProME 提供公开 PDF 和 Notes。GRA-Flow、RECAST 按用户要求只展示论文信息，不公开 PDF 或完整笔记，也不通过标题、配图和站点地图暴露笔记入口。

两篇完整笔记、PDF 网站副本和原始依据说明保存在本机被 Git 忽略的 .private/，不进入网站构建或托管源码。重新公开须由用户明确要求；届时从本地草稿恢复文章与文件，核对投稿状态，再同步开放资源入口。

src/data/publications.json 保存公开列表信息，src/data/articles.json 只保存当前公开的三篇文章。源码历史中的旧版本不因本次撤下而自动删除。
