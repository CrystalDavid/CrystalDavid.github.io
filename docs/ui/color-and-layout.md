# 颜色与布局规范

## 颜色令牌

| CSS 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#fffefe` | Hero 白色页面 |
| `--cream` | `#fdf0e5` | Agent 章节与产品展示暖色背景 |
| `--sky` | `#eefbff` | Article 区浅蓝背景 |
| `--mist` | `#f0f4ff` | About 与页脚浅雾蓝背景 |
| `--ink` | `#2229bd` | 主标题和主要文字 |
| `--action` | `#0562ee` | 链接、按钮、品牌和高亮 |
| `--text-soft` | `#414797` | 次级正文 |
| `--hairline` | `#b8d0ff` | 按钮边框和细线 |
| 页面底色 | `#e7edfb` | 圆角页面之间的底层背景 |

英文 Hero 副标题使用从 `#2229bd` 经 `#0562ee` 到 `#f2a7a7` 的 100° 渐变。选择文字为白色、背景为 `--action`。焦点环固定为 3px `#ffca45`，不能只保留 hover 而删除键盘焦点。

## 页面结构

- 所有全屏章节使用 `.screen`，最小高度为 `--app-viewport-height`，圆角 `12px`。
- 桌面水平基准边距为 50px；移动端根边距为 18px。
- 顶栏固定于视口，桌面 top 34px，移动 top 18px。
- Hero 内容水平居中，最大宽度 1500px。
- About 文本桌面最大宽度 900px，正文最大宽度 800px。
- 页脚桌面为三列；移动端前两列并排、联系区跨两列。

## 控件

- 语言按钮桌面 127×45、圆角 26px；hover 变为 `--action` 蓝底白字并上移 1px。
- 产品按钮英文 172×60、中文 190×64，边框 `--hairline`、胶囊圆角 `999px`；视觉语言与中英文切换按钮一致。
- 所有按钮文字继承全站字体；禁止浏览器默认 serif 或单独的小字号。
