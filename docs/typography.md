# 网站视觉规范

本文件是首页及 404 页面字体、颜色、字号、行高、间距和响应式布局的唯一规范。实现位于 `src/styles/global.css`；修改任意一方时同步另一方。`AGENTS.md` 和 `README.md` 仅提供入口。

## 字体与主题

全站使用本地 Nunito，包括正文、姓名、学校、导航、作者及按钮，仅使用 400 和 700 两档字重。姓名、栏目标题、论文/项目标题、学校、本人署名、时间轴年份、全部导航、About Me 正文和研究兴趣使用 700；学位专业、其他作者、项目类别、资源按钮与 404 辅助文字使用 400。保留现有字体文件、许可证、Nunito latin 预加载及 `font-display: block`，优先保证字体统一和排版稳定。缺失字形使用现有 Noto Sans SC 与系统字体后备，不预加载后备字体。

背景固定白色，使用 `color-scheme: only light` 和浅色页面元数据。布局、文字及资源均不随系统外观切换。

## 文字颜色

常驻文字仅使用三种颜色；背景、边框、阴影、图片内容和选择高亮不计入字体色。

| 色值 | 变量 | 用途 |
| --- | --- | --- |
| `#16324F` | `--ink` | 姓名、栏目标题、全部论文/项目标题、学校、时间轴年份、本人署名、资源按钮、普通按钮导航、社交图标 |
| `#243B53` | `--secondary`；`--body` / `--muted` 引用它 | About Me 正文、研究兴趣、学位专业、其他作者、项目类别、经典布局年份与普通导航、404 辅助文字 |
| `#2867A5` | `--accent` | 当前导航、404 返回主页链接；资源按钮及社交图标悬停 |
| `#174878` | `--accent-hover` | 404 返回主页链接悬停，仅交互态 |
| `#FFFFFF` | — | Skip to content 键盘焦点文字，仅交互态 |

资源按钮和社交图标悬停使用 `--accent`。普通 strong 继承所在文字的颜色。文字与白色背景的对比度至少达到 4.5:1。

论文/项目标题统一使用无链接的深蓝文字。About Me 中的学校名称为正文的一部分，不单独设色或添加链接。首页文本外链通过 arXiv / Code / Demo 及社交入口访问，项目配图也可打开对应仓库。

边框与教育分隔线为 `#DCE5EE`，资源按钮边框为 `#7C8C9B`，图片阴影为 `#B0B0B0`，选择背景为 `#DAEDF7`。资源按钮无填充。导航按钮普通态白底、浅色边框，悬停及当前项使用 `--nav-surface: #F1F6FB` 浅蓝背景与蓝色边框。校徽保留官网原色。favicon 保持 `#3399CC` 实心圆润闪电、透明背景；共享 SVG、PNG 与 ICO 资源，保留小尺寸轮廓补偿。

共六档字号；各屏幕沿用相同字号，靠换行和布局调整适配。研究兴趣各条目不另加上下 margin，连续单行条目的基线间距为 30.6px；长条目换行后也使用此行高。全站没有额外字距设置。行高是每行占据的高度，不等于两行字形之间的纯空白。

Education 时间轴在桌面和平板从左到右为年份、竖线、南科大校徽、学校及学位专业。学校全称使用 18px / 700，完整学位专业使用 16px / 400，年份使用 16px / 700。校徽等比显示，不添加卡片阴影。手机将年份放在上方独立一行，下方按竖线、校徽、学校与学位专业排列，为完整文字留出空间；文字自然换行，不截断或缩小字号。

Education 经典布局为：26px 栏目标题，18px 海军蓝加粗学校，16px 蓝黑色学位专业与年份。桌面学校与年份同一行，学位专业占下一行；手机按学校、学位专业、年份排列。

作者名单保留原顺序与本人姓名加粗。桌面可向右侧留白延伸，空间不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 可选样式

`src/data/presentation.ts` 独立控制两处样式，当前使用 `education: 'timeline'`、`navigation: 'classic'`。Education 可选 `timeline` / `classic`，导航可选 `classic` / `buttons`，两项互不影响。Education 两套结构保存在 `src/components/Education.astro`，导航两套样式按类名隔离保存在全局 CSS。切换在构建时完成，访客只收到选中的结构，没有额外切换脚本或公开样式开关。

## 间距

间距按 CSS 布局边界计算，不含字形内部留白和图片阴影。相邻垂直 margin 按折叠规则计算。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Education → Research Interests → Publications，相邻板块 | 48px | 40px | 40px |
| Publications → Projects | 56px | 48px | 40px |
| 栏目标题至首项内容 | 18px | 18px | 18px |
| 相邻论文或项目条目 | 42px | 42px | 32px |
| 图片外框至文字区域 | 横向 33px | 横向 33px | 上下 18px |

板块基础间距使用 `--section-gap`；论文板块后的 `--figure-section-gap` 在桌面/平板增加 8px 阴影补偿。手机条目以文字或按钮结尾，不加补偿。板块末项无底部外边距，条目首项无额外上边距。标题下方共用 `--heading-content-gap`。

桌面/平板图文列的 grid gap 为 28px，图片外框另有右侧 margin 5px，因此外框边缘至文字的实际距离为 33px。图文垂直居中，顶端不强行对齐；标题换行会改变文字块高度。手机使用上下布局，图片底边至文字块顶边为 18px。图片内部图形自带的留白和阴影不计入这些值。

## 布局与交互

桌面宽度 960px：侧栏 232px、列间距 78px、正文 650px。侧栏 sticky 并可在窗口较矮时独立滚动。≤1000px 为单栏，最大宽度 720px、左右内边距 25px；≤520px 左右内边距 20px。顶部留白依次为 64px、50px、28px。

正文底部内边距 40px。单栏个人资料区底部 25px，内容区顶部分隔线后留 25px。姓名下方 margin 为桌面 22px、单栏 15px，副行上方 4px；社交图标行上方为桌面 24px、单栏 15px。头像外框底部 margin 为桌面 10px、单栏 8px。

| 侧栏与页面细部 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| 头像图片尺寸 | 104×104px | 104×104px | 88×88px |
| 头像外框尺寸 / 内边距 | 144×144px / 20px | 128×128px / 12px | 112×112px / 12px |
| 头像图片底边至姓名块 | 30px | 20px | 20px |
| 姓名块至社交图标区域 | 24px | 15px | 15px |
| 社交图标区域至导航 | 28px | 20px | 20px |
| 主内容区顶部内边距 | 64px | 25px | 25px |
| 主内容区底部内边距 | 40px | 40px | 40px |

姓名与社交区域的相邻 margin 会折叠，桌面实际间距是 24px，不是 22px + 24px。单栏中导航下方有个人资料区底部 padding 25px、1px 分隔线，再到主内容区顶部 padding 25px。

404 内容区额外向下留 30px；提示行至标题 18px，标题至说明 20px，说明段底部 margin 为 18px。返回链接是较小的行内文字，说明行框至链接自身边界实测约 23px，包含行内排版的垂直对齐空间。

键盘 Skip to content 入口位于顶部 15px、左侧 20px，内边距为上下 8px、左右 15px；仅获得焦点时显示。链接焦点轮廓 2px、外偏移 4px。页面锚点使用 html 顶部滚动留白 32px 与栏目 scroll-margin 32px，常规定位总留白为 64px；接近页尾时受浏览器可滚动范围限制。

使用浏览器原生锚点与滚动；导航点击、键盘激活及直接打开带 hash 的链接均可定位栏目。滚动时更新当前项，点击页尾栏目后保持所选项，继续手动滚动时恢复跟踪。减少动态效果偏好下关闭平滑滚动和页面过渡。无 JavaScript 时，导航和全部内容仍可使用。

## 验收

运行 check、build、test；检查首页与 404 在电脑、手机及两种浏览器颜色偏好下的表现。验证五个导航目标、当前项跟踪、键盘焦点、浏览器前进后退、页尾跳转、作者局部滚动、图片和无整页横向溢出。核对六档字号、三种常驻文字颜色、两档字重和 Education 层级。修改可选布局时，在独立验证副本中检查两项均为经典布局，以及分别切换的组合；发布前恢复默认配置。

本地查看与检查命令见 [README](../README.md)，内容依据见 [研究资料来源](research-sources.md)。
