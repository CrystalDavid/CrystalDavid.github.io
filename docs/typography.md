# 网站视觉规范：字体、颜色、字号、行高与间距

固定浅色蓝色主题，覆盖首页、三篇公开文章和 404 页面。

这是全站视觉设计的唯一规范文件。`AGENTS.md` 要求后续修改读取并遵守本文件，`README.md` 只提供入口。实现位于 `src/styles/global.css`；修改 CSS 或规范时同步另一方，避免多份数值漂移。桌面与手机均遵守本规范，不另增近似字号、灰色或同类间距。

## 核对口径

通过浏览器 getComputedStyle 检查实际显示的 HTML 文字，包括文章正文与代码。排除隐藏内容、图片/SVG 内文字、favicon 和浏览器界面；默认态和悬停/焦点态分别统计。字体颜色不包含背景、边框、阴影和选择高亮。间距按 CSS 像素和布局边界计算，文字字形留白与阴影不包含在布局框内；相邻垂直 margin 折叠，不直接相加。

## 字体

正文、学校、目录、链接、作者、元信息、全部按钮（包括 Copy）、代码正文及工具栏语言标签全部使用本地 Nunito，共用 --font-interface。缺失字形由 Noto Sans SC 和系统字体后备。代码保留原始字符、缩进、换行和局部横向滚动。

字体统一和排版稳定优先：保持现有字体文件、Nunito latin 预加载及 `font-display: block`。现有 Nunito 不包含箭头字形，`→` 使用 Noto Sans SC，该后备字体不预加载。公开代码示例使用英文说明，保留 JSON 键名、结构、缩进和换行。

普通文字使用 400 字重；姓名、标题、本人姓名和正文强调使用 700 字重。全站只有这两档字重。

## 文字颜色：常驻 3 种，含交互共 5 种

| 色值 | 用途 |
| --- | --- |
| #043361 | 姓名、栏目/文章标题、章节序号、作者姓名强调、资源按钮；社交图标同色 |
| #3399cc | 普通链接、论文/项目标题、当前目录项 |
| #444444 | 全站正文、学校/专业、普通目录项、作者列表、摘要、投稿状态、项目类型、阅读时间、代码正文、语言标签及 Copy |
| #006699 | 普通链接悬停（交互态） |
| #ffffff | 跳过导航的键盘焦点文字（交互态） |

普通 strong 继承当前颜色。首页和全站均只使用三种常驻文字色，背景、边框、阴影和选择高亮不计作字体颜色。

CSS 映射：--ink 为深蓝，--accent 为链接蓝，--accent-hover 为悬停蓝；--secondary 为 #444444，--body / --muted 引用它。普通文字链接悬停使用 #006699，资源按钮和社交图标悬停使用 #3399cc；Copy 保持工具栏深灰。

背景固定 #FFFFFF，color-scheme: only light，不随系统外观改变。边框 #E5E5E5、按钮边框 #7C8C9B、图片阴影 #B0B0B0、工具栏背景 #F8F8F8、代码背景 #FAFAFA、选择背景 #DAEDF7；这些不是额外字体颜色。

浏览器标签页使用圆润闪电：透明底、#3399cc 实心轮廓，尖端与转折圆润，视觉中心居中，轮廓充分利用画布且不裁切。不添加底色、描边、阴影、动画或字母。全站共享 SVG、16/32px PNG 和含 16/32/48px 图层的 ICO，保留小尺寸轮廓补偿。资源为 `public/favicon-lightning-large.svg`、`public/favicon-lightning-large-16.png`、`public/favicon-lightning-large-32.png` 与 `public/favicon.ico`。

## 字号：5 档文字 + 14px 按钮，共 6 种

| 字号 | CSS 变量 | 用途 |
| --- | --- | --- |
| 14px | --text-button | arXiv / Notes / Code / Demo / Article 等胶囊按钮、代码 Copy 按钮 |
| 16px | --text-meta；--text-small 引用同一值 | 学校/专业、作者与投稿信息、项目类别、章节序号、目录、返回/来源链接、阅读时间、代码及工具栏标签 |
| 18px | --text-body | 首页和文章正文、文章摘要、论文/项目标题、404 正文 |
| 22px | --text-subheading | (Dawei HUANG)、文章内三级标题 |
| 26px | --text-heading | 首页栏目标题、文章章节标题 |
| 32px | --text-title | David、文章主标题、404 标题 |

首页、文章页、桌面和手机共用五档文字字号，按钮单独使用 14px，不影响其他文字。侧栏目录和返回链接与学校文字使用同一套 Nunito、16px、400 字重和 1.7 行高。正文和论文标题同为 18px，分别使用常规深灰和粗体蓝色，保留阅读层次。

## 行高

| 内容 | 倍数 | 实际行高 |
| --- | --- | --- |
| 首页正文、文章正文、摘要 | 1.7 | 30.6px |
| 作者、首页和文章投稿信息、项目类别 | --line-meta = 1.65 | 26.4px |
| 学校/专业、侧栏目录和返回链接 | 1.7 | 27.2px |
| 论文/项目标题 | 1.5 | 27px |
| 首页栏目标题、文章章节标题（均 26px） | --line-heading = 1.3 | 33.8px |
| 文章三级标题 | 1.35 | 29.7px |
| 文章主标题 | 1.25 | 40px |
| 资源按钮、Copy 按钮 | 1.5 | 21px |
| 代码工具栏标签 | 1.5 | 24px |
| 代码正文 | 1.65 | 26.4px |
| David / (Dawei HUANG) | 1.2 | 38.4 / 26.4px |
| 404 主标题 | 1.4 | 44.8px |
| 文章章节序号 | 继承 h2 的 1.3 | 20.8px |

同类 26px 标题必须共用 1.3 行高；同类作者/投稿信息共用 1.65。姓名、文章主标题、代码与正文承担不同角色，保留上表明确列出的差异。

作者名单统一单行，保留原顺序和本人姓名加粗。桌面可向右侧留白延伸；屏幕不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 间距与视觉校准

图片阴影会占据部分下方留白，因此图片结尾的板块额外补偿 8px，使图片下缘到下一标题的视觉距离与文字结尾的板块一致。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Research Interests | 48px | 40px | 40px |
| Research Interests → Publications | 48px | 40px | 40px |
| Publications → Projects | 56px | 48px | 40px |
| Projects → Beyond Research | 56px | 48px | 40px |
| 文章章节之间 | 48px | 40px | 40px |
| 正文栏目标题至正文 | 18px | 18px | 18px |
| 论文/项目栏目标题至第一条 | 24px | 24px | 24px |
| 相邻论文或项目条目 | 42px | 42px | 32px |
| 配图与条目文字 | 横向 28px | 横向 28px | 上下 18px |

表中板块间距为容器边界数值，不等同于字体墨迹/阴影边缘的距离。基础间距使用 --section-gap，图片结尾板块使用 --figure-section-gap。额外 8px 是阴影补偿，不能机械合并；两处图片结尾采用同一规则。手机图片位于条目文字上方，板块以文字或按钮收尾，因此不额外补偿。

## 其余布局

桌面内容宽度保持 960px：左栏 232px、列间距 78px、右栏 650px。单栏最大 720px，左右内边距 25px，手机为 20px。顶部留白桌面 64px、平板 50px、手机 28px。保留原图片、圆角、固定浅色背景及原生滚动方式。

- 右栏底部内边距 40px；单栏侧栏底部 25px，内容区顶部分隔线后留 25px。
- 首页姓名底部 margin 为桌面 22px、单栏 15px；文章侧栏为桌面 18px、单栏 8px。文章侧栏隐藏专业信息，单栏同时隐藏学校与目录。
- 首页社交图标行顶部 margin 为桌面 24px、单栏 15px；文章侧栏为桌面 12px、单栏 7px。
- 侧栏目录 margin 为上方 15px、下方 30px，左右内边距 10px。姓名副行上方 margin 为 4px。
- 首页头像外框底部 margin 为桌面 10px、单栏 8px，文章侧栏为 8px。
- 以上侧栏差异用于压缩文章导航，不改变学校/目录的统一字体、字号和行高。

## 验收与后续修改

1. 运行项目已有的 check、build、test；检查首页、三篇文章及 404 的桌面/手机布局，浅/深色偏好均保持白色。
2. 确认六档字号、三种常驻色、两档字重；Copy 为 Nunito 14px/21px，代码为 Nunito 16px/26.4px，工具栏标签为 Nunito 16px/24px。
3. 确认首页及文章 h2 都为 26px/33.8px，投稿信息都为 16px/26.4px；段落 18px、摘要/状态下方 16px、文章 h3 上方 24px。
4. 确认板块间距、作者单行及局部滚动、图片、文章导航和返回锚点，公开内容遵守 [研究资料来源](research-sources.md)。
5. 修改后的规范与 CSS 必须一致；检查命令、发布步骤和线上核对要求见 [部署说明](deployment.md)。
