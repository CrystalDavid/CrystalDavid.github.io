# 网站视觉规范

本文件是首页及 404 页面字体、颜色、字号、行高、间距和响应式布局的唯一规范。实现位于 `src/styles/global.css`；修改任意一方时同步另一方。`AGENTS.md` 和 `README.md` 仅提供入口。

## 字体与主题

全站使用本地 Nunito，仅使用 400 和 700 两档字重。About Me 正文、研究兴趣、学位专业、其他作者、项目类别、资源按钮与 404 辅助文字使用 400；姓名、栏目标题、论文/项目标题、学校、本人署名、时间轴年份、全部导航使用 700。切换当前导航项不改变字重，避免文字宽度变化。

保留字体文件、许可证、Nunito latin 预加载及 `font-display: block`，保证字体与排版稳定。缺失字形使用现有 Noto Sans SC 与系统字体后备，不预加载后备字体。

背景固定白色，使用 `color-scheme: only light` 和浅色页面元数据，不随系统外观切换。

## 文字颜色

常规文字及其悬停状态共用两种颜色；背景、边框、阴影、图片内容不计入字体色。

| 色值 | 变量 | 用途 |
| --- | --- | --- |
| `#243B53` 蓝黑 | `--ink`；`--body` / `--muted` 引用它 | 姓名、所有标题、正文、学校、年份、作者、学位专业、项目类别、普通导航、资源按钮、社交图标 |
| `#2867A5` 蓝色 | `--accent` | 当前导航、404 返回链接及其悬停状态、资源按钮和社交图标悬停 |
| `#FFFFFF` | — | Skip to content 键盘焦点文字，仅无障碍入口的例外 |

普通 strong 继承所在文字的颜色，通过字重体现层级。论文/项目标题均为无链接的蓝黑文字；About Me 学校名称不单独设色或加链接。外部文本链接通过 arXiv / Code / Demo 及社交入口访问，项目图片也可打开对应仓库。

边框与教育分隔线为 `#DCE5EE`，资源按钮边框为 `#7C8C9B`，图片阴影为 `#B0B0B0`，选择背景为 `#DAEDF7`。资源按钮无填充；备用导航按钮普通态白底，悬停和当前项使用 `#F1F6FB` 浅蓝背景及蓝色边框。校徽保留官网原色。favicon 保持 `#3399CC` 实心圆润闪电、透明背景及小尺寸轮廓补偿，使用共享 SVG、PNG 和 ICO。

## 字号、行高与字重

六档字号，五档整数行高；各屏幕沿用同一套数值，依靠换行与布局适配。

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| arXiv / Code / Demo 资源按钮 | 14px | 24px | 400 |
| 学位专业、其他作者、项目类别、经典布局年份、404 返回链接 | 16px | 28px | 400 |
| 全部导航、时间轴年份、作者中的本人姓名 | 16px | 28px | 700 |
| About Me、研究兴趣、404 辅助文字、Skip to content | 18px | 32px | 400 |
| 学校名称 | 18px | 32px | 700 |
| 论文与项目标题 | 18px | 28px | 700 |
| (Dawei HUANG) | 22px | 28px | 700 |
| 栏目标题 | 26px | 36px | 700 |
| David、404 主标题 | 32px | 40px | 700 |

字号依次由 `--text-button`、`--text-meta`、`--text-body`、`--text-subheading`、`--text-heading`、`--text-title` 控制。行高使用 `--line-compact: 24px`、`--line-meta: 28px`、`--line-body: 32px`、`--line-heading: 36px`、`--line-title: 40px`，不要为单个组件新增相近倍数或小数档位。

研究兴趣不另加条目 margin，连续单行条目的基线间距为 32px，换行后仍使用同一行高。圆点使用直径 6px 的 CSS 圆形，距首行行框顶部 13px，与首行垂直居中；圆点右边缘至文字容器为 24px。列表左侧内边距 20px，文字从左侧 50px 起排，换行沿文字左边缘对齐。保留 `ul` / `li` 结构及显式 `role="list"`，不依赖浏览器默认圆点间距。无额外字距设置。行高包含字形本身，不等于字形之间的纯空白。

作者名单保留原顺序及本人姓名加粗。桌面可向右侧留白延伸，空间不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 内容间距

主要内容留白采用 4px 倍数，按细部、组内、条目、板块分层。以下是 CSS 布局边界的距离，不含字形内部留白和图片阴影。

元素之间的对齐间距通过共享变量控制：`--control-gap: 16px` 用于并排资源按钮及备用按钮导航的横向间距；`--item-gap: 24px` 用于社交图标外框、Education 各列、研究兴趣圆点与文字，以及备用编号导航的序号与文字；`--media-gap: 32px` 用于论文／项目图片外框与文字，横向或上下排列均使用同一数值。当前导航不显示序号。此规则不改变字号、行高、控件内部留白、段落及板块间距。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Education → Research Interests → Publications，相邻板块 | 56px | 48px | 48px |
| Publications → Projects | 64px | 56px | 48px |
| 栏目标题至首项内容 | 24px | 24px | 24px |
| 相邻论文或项目条目 | 48px | 48px | 40px |
| 图片外框至文字区域 | 横向 32px | 横向 32px | 上下 32px |
| 普通段落之间 | 24px | 24px | 24px |
| 条目标题至作者或类别 | 8px | 8px | 8px |
| 作者或类别行框至资源按钮上边缘 | 16px | 16px | 16px |

板块基础间距使用 `--section-gap`，论文板块之后的 `--figure-section-gap` 在桌面/平板多留 8px 补偿图片阴影，使视觉留白接近纯文字板块。手机条目以文字或按钮结尾，不加补偿。板块末项无底部 margin，条目首项无额外上边距。标题下方共用 `--heading-content-gap`，段落共用 `--paragraph-gap`。

图文在桌面/平板垂直居中，手机为图片在上、文字在下。论文与项目图片没有外加标签或裁剪。图片外框与标题区域的间距使用 grid gap，不叠加图片 margin；图片内部图形自带的留白不计入间距。

条目内按字形的视觉留白对齐：标题至作者/类别使用 8px 行框间距，作者/类别至按钮边缘使用 16px。两行文字的字形外都有行高留白，按钮边框不带这部分留白，因此使用不同的 CSS 间距，使“标题字形下沿→下一行字形上沿”与“下一行字形下沿→按钮上沿”看起来接近。

## 侧栏、导航与按钮

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| 侧栏顶部留白 | 64px | 48px | 32px |
| 头像图片尺寸 | 104×104px | 104×104px | 88×88px |
| 头像外框 / 内边距 | 144×144px / 20px | 128×128px / 12px | 112×112px / 12px |
| 头像图片底边至姓名块 | 32px | 32px | 32px |
| David 与副行之间 | 4px | 4px | 4px |
| 姓名块至社交图标区域 | 32px | 32px | 32px |
| 社交图标区域至导航 | 32px | 32px | 32px |
| 普通 / 经典导航项间距 | 4px | 行 4px、列 24px | 行 4px、列 24px |
| 首页主内容区顶部内边距 | 76px | 32px | 32px |
| 主内容区底部内边距 | 64px | 64px | 64px |

默认普通导航不显示序号，所有标签沿同一左边缘对齐。普通与备用经典编号导航均使用最小点击高度 44px，全部状态为 16px / 28px / 700。桌面左右容器内边距 16px，导航下方 margin 24px；链接上下内边距 6px、左侧 12px，当前项为蓝色文字与左侧 2px 竖线。经典编号样式保留序号至文字间距 24px。移动端链接左右无内边距，当前项改用底部 2px 横线；经典样式也隐藏序号。其他项使用透明边框，切换时不位移。单行点击区域实测为 44px。

备用按钮导航项纵向间距 8px，横向并排时相隔 16px；内边距上下 8px / 左右 16px，边框 1px、圆角 12px、最小高度 48px；文字居中、无序号。

社交图标外框为 24×24px，外框之间相隔 24px；点击区域保持 40×40px。每个图标在点击区域左右各留 8px，因此点击区域间距使用 `calc(var(--item-gap) - 16px)`，实际为 8px。SVG 路径内部留白不计入外框间距，两个可见轮廓之间约为 26px。

资源按钮字体 14px、行高 24px、上下内边距 0px / 左右 8px、边框 1px，总高度 26px。按钮使用 `border-radius: 13px`，圆角半径为高度的一半，形成上下平直、两端半圆的胶囊轮廓；文字水平和垂直居中，按钮间距 16px。宽度按标签内容自动确定；仅使用原生 CSS，不依赖脚本或实验性角形属性。整数高度由既有 24px 行高与上下边框组成，不新增行高档位。

## 图片与页面布局

| 图片细部 | 桌面 / 平板 | 手机 |
| --- | --- | --- |
| 论文与项目图片外框 | 192×128px | 240×160px |
| 图片外边距 | 0 | 上下 0、水平居中 |
| 论文图片内边距 | 8px | 8px |
| 项目图片内边距 | 0 | 0 |
| 图片圆角 | 8px | 8px |
| 阴影 | 水平 3px、垂直 3px、模糊 6px | 同左 |

桌面外框宽 960px：左侧内边距 48px、侧栏 232px、列间距 32px、正文 648px。头像、姓名、社交图标和导航随侧栏整体定位；侧栏 sticky，窗口较矮时可独立滚动。≤1000px 为居中单栏，最大宽度 720px，左右内边距 24px；≤520px 左右内边距 20px。单栏个人资料区底部留 32px，经 1px 分隔线后，主内容区顶部再留 32px。

首页桌面默认采用 `homeAlignment: 'avatar'`：主内容顶部内边距为 76px，结合 Nunito 标题行框内约 8px 的字形留白，使 About Me 的可见字形顶部与距页面顶部 84px 的头像图片对齐。`homeAlignment: 'classic'` 保留 64px 顶部内边距，可单独切回；两种配置在单栏屏幕上均使用 32px。

404 主内容区顶部内边距为桌面 64px、单栏 32px，不受首页对齐配置影响。404 内容区额外向下留 32px；提示行、主标题、说明、返回链接依次间隔 24px。返回链接单独成块，使间距不受行内基线影响。

键盘 Skip to content 入口获得焦点时出现在顶部 16px、左侧 20px，内边距上下 8px / 左右 16px。链接焦点轮廓为 2px、外偏移 4px。页面锚点使用 html 顶部滚动留白 32px 与栏目 scroll-margin 32px，常规定位总留白为 64px；页尾受浏览器可滚动范围限制。

## 可选样式与交互

`src/data/presentation.ts` 独立控制教育样式、导航样式和首页顶部对齐，当前为 `education: 'timeline'`、`navigation: 'plain'`、`homeAlignment: 'avatar'`。Education 可选 `timeline` / `classic`，导航可选无序号的 `plain` / 带序号的 `classic` / 按钮形式的 `buttons`，首页对齐可选 `avatar` / `classic`。两套教育结构保存在 `src/components/Education.astro`，导航与首页对齐样式按类名隔离保存在全局 CSS。切换在构建时完成，访客只收到选中的结构，没有运行时样式开关。

使用浏览器原生锚点与滚动。导航点击、键盘激活及直接访问 hash 均可定位；滚动更新当前项，点击页尾栏目后保持所选项，手动滚动恢复跟踪。减少动态效果偏好关闭平滑滚动和页面过渡。无 JavaScript 时导航与内容仍可使用。

## 验收

运行 check、build、test；检查电脑、手机、两种浏览器颜色偏好。验证五个导航目标、当前项跟踪、键盘焦点、前进后退、页尾跳转、作者局部滚动、图片和无整页横向溢出。核对六档字号、五档整数行高、两种常规文字颜色、两档字重与 Education 层级。

修改共用视觉规则后，在验证副本中检查经典 Education、编号导航、按钮导航及其独立组合；涉及首页顶部对齐时验证两种位置配置，发布前恢复默认配置。当前说明只描述生效规则和可用配置，不记录变更历史。

本地查看与检查命令见 [README](../README.md)，内容依据见 [研究资料来源](research-sources.md)。
