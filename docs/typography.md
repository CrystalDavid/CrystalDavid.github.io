# 字体颜色与字号清单

统计日期：2026-10-16。修改后版本，覆盖首页、五篇文章和 404 页面。

## 统计口径

在 Microsoft Edge 中读取实际显示文本的 `getComputedStyle`，检查 390、768、1440px 三种宽度和浅/深色两种外观，共 42 种页面状态。包括滚动后可见的正文，排除隐藏元素、图片内文字、favicon 和浏览器界面。悬停、键盘焦点与跳过导航另行检查，未增加新的文字颜色或字号。

## 实际文字颜色

- 浅色模式：5 种（4 种灰色 + 白色）。
- 深色模式：4 种（3 种灰色 + 白色）。
- 两种模式合并去重：8 个色值，白色只计算一次。
- 首页单独统计：浅色 4 种、深色 3 种。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 正文、姓名、标题、链接、按钮文字、作者姓名强调 | #595959 | #b8b8b8 |
| 投稿状态/项目类型、文章正文 | #444444 | #b8b8b8 |
| 论文/项目摘要、代码正文 | #333333 | #c6c6c6 |
| 阅读时间、文章状态说明、代码工具栏 | #777777 | #a0a0a0 |
| 缩略图标签文字、键盘聚焦时的跳过导航文字 | #ffffff | #ffffff |

原蓝色的标题、链接和作者强调已与简介正文共用颜色。边框、图标、标签背景、选择高亮和 favicon 也已改成中性灰；图片保留原色。标题依靠字号/字重区分，段落中的链接用下划线提示，目录当前项和悬停链接也有下划线。

CSS 还保留通用 `strong` 的 #222222（浅色）和 #e0e0e0（深色）作为未来内容样式，但当前实际 `strong` 均被作者姓名样式覆盖。因此这两个未出现的色值不计入上面的实际数量；若只数所有已定义文字色，则浅色 6 种、深色 5 种。

## 实际字号：15 种

| 字号 | 实际用途 |
| --- | --- |
| 12px | PDF / Code / Notes 等胶囊按钮、缩略图标签、代码工具栏、手机代码正文 |
| 13px | 桌面文章目录、阅读时间、文章状态、桌面代码正文 |
| 14px | 作者/投稿信息、文章来源/返回链接、手机左栏专业 |
| 15px | 桌面左栏专业、论文/项目说明 |
| 16px | 首页简介/研究兴趣/学校、桌面条目标题、手机文章正文 |
| 17px | 文章摘要与桌面正文、章节序号、手机条目标题 |
| 20px | 文章内三级标题 |
| 22px | 文章页左栏的 (Dawei HUANG) |
| 23px | 首页的 (Dawei HUANG)、手机文章二级标题 |
| 25px | 文章页左栏 David、桌面文章二级标题 |
| 25.12px | 首页栏目标题 |
| 27px | 手机首页 David |
| 28px | 桌面首页 David、404 标题 |
| 29px | 手机文章主标题 |
| 32px | 桌面文章主标题 |

首页桌面为 7 种：12、14、15、16、23、25.12、28px；首页手机为 8 种：12、14、15、16、17、23、25.12、27px。全站数量包含响应式变体，并非单个页面同时显示 15 种字号。favicon SVG 内的 D 是 49 个 SVG 用户单位，不是页面 CSS 字号，不计入。

主字体为 Nunito；代码块为 Ubuntu Mono；Noto Sans SC 等为后备字体。此次只调整颜色，保留既有字体、字号与布局。

## 后续建议（尚未实施）

15 种字号偏细碎，尤其 25 与 25.12、27 与 28px 区别很小。后续可以统一为约 6–7 个语义字号，并把正文颜色收敛为正文/次要信息/反白三种角色。当前清单描述实际代码，不把建议写成已完成改动。
