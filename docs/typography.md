# 全站字体、颜色与间距清单

更新日期：2026-10-17。固定浅色蓝色主题，覆盖首页、三篇公开文章和 404 页面。

## 实测口径

通过 Microsoft Edge 的 getComputedStyle 检查实际显示的 HTML 文字，包括文章正文与代码。排除隐藏内容、图片/SVG 内文字、favicon 和浏览器界面；默认态和悬停/焦点态分别统计。上一轮五页覆盖 320/390/1440px，含浅/深色偏好共 30 种布局状态；本轮针对按钮调整复核首页与 ProME 的 5 种桌面/手机状态。

## 字体

主字体仍为本地 Nunito，代码使用 Ubuntu Mono；非英文字符保留 Noto Sans SC 和系统字体后备。

## 文字颜色：常驻 3 种，含交互共 5 种

| 色值 | 用途 |
| --- | --- |
| #043361 | 姓名、栏目/文章标题、作者姓名强调、资源按钮；社交图标同色 |
| #3399cc | 普通链接、论文/项目标题、当前目录项 |
| #444444 | 全站正文、学校/专业、普通目录项、作者列表、摘要、投稿状态、项目类型、阅读时间、代码正文及工具栏 |
| #006699 | 普通链接悬停（交互态） |
| #ffffff | 跳过导航的键盘焦点文字（交互态） |

原 #595959、#333333 与 #777777 均并入 #444444。普通 strong 继承当前颜色。首页和全站均只使用三种常驻文字色，背景、边框、阴影和选择高亮不计作字体颜色。已删除的项目说明不会重新出现。

## 字号：5 档文字 + 14px 按钮，共 6 种

| 字号 | CSS 变量 | 用途 |
| --- | --- | --- |
| 14px | --text-button | PDF / arXiv / Notes / Code / Demo / Article 等胶囊按钮、代码 Copy 按钮 |
| 16px | --text-meta；--text-small 引用同一值 | 学校/专业、作者与投稿信息、项目类别、章节序号、目录、返回/来源链接、阅读时间、代码及工具栏标签 |
| 18px | --text-body | 首页和文章正文、文章摘要、论文/项目标题、404 正文 |
| 22px | --text-subheading | (Dawei HUANG)、文章内三级标题 |
| 26px | --text-heading | 首页栏目标题、文章章节标题 |
| 32px | --text-title | David、文章主标题、404 标题 |

首页、文章页、桌面和手机共用五档文字字号，按钮单独使用 14px，不影响其他文字。侧栏目录和返回链接与学校文字使用同一套 Nunito、16px、400 字重和 1.7 行高。正文和论文标题同为 18px，分别使用常规深灰和粗体蓝色，保留阅读层次。

## 间距与视觉校准

此前桌面四组相邻板块的容器间距确实都是 48px，但图片阴影会占据部分下方留白，视觉上比文字结尾的板块更紧。现在对图片结尾的两处额外补偿 8px，让图片下缘至下一标题更加接近研究兴趣列表下方的留白。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Research Interests | 48px | 40px | 40px |
| Research Interests → Publications | 48px | 40px | 40px |
| Publications → Projects | 56px | 48px | 40px |
| Projects → Beyond Research | 56px | 48px | 40px |
| 文章章节之间 | 48px | 40px | 40px |
| 正文栏目标题至正文 | 18px | 18px | 18px |
| 论文/项目栏目标题至第一条 | 24px | 24px | 24px |
| 相邻论文或项目条目 | 42px | 42px | 32px |
| 配图与条目文字 | 横向 28px | 横向 28px | 上下 18px |

表中板块间距为容器边界的 CSS 数值，不等同于字体墨迹/阴影边缘的距离。1440px 下，两处图片盒子下缘到下一标题文字的距离均约 66px；阴影占据一部分后，与研究兴趣最后一行文字到下一标题约 59px 的留白接近。手机图片位于条目文字上方，板块以文字或按钮收尾，因此不额外补偿。

## 其余布局

桌面内容宽度保持 960px：左栏 232px、列间距 78px、右栏 650px。单栏最大 720px，左右内边距 25px，手机为 20px。顶部留白桌面 64px、平板 50px、手机 28px。保留原图片、圆角、固定浅色背景及原生滚动方式。

## 验证

此前 30 种页面/视口/外观状态验证了五档文字字号和三种常驻颜色，侧栏与学校字体一致。本轮仅增加按钮专用 14px 档位，并复核资源按钮、Copy、目录和其他辅助文字；其余字号、颜色、内容和间距保持原规则。详见 docs/verification.md。
