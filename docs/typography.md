# 网站视觉规范

本文件是首页及 404 页面字体、颜色、字号、行高、间距和响应式布局的唯一规范。实现位于 `src/styles/global.css`；修改任意一方时同步另一方。`AGENTS.md` 和 `README.md` 仅提供入口。

## 字体与主题

全站使用本地 Nunito，仅使用 400 和 700 两档字重。About Me 正文、研究兴趣、学位专业、其他作者、项目类别、资源按钮与 404 辅助文字使用 400；姓名、栏目标题、论文/项目标题、学校、本人署名、时间轴年份、全部导航使用 700。切换当前导航项不改变字重，避免文字宽度变化。

Nunito 使用 400、700 两个固定字重，每档分为常用英文 core、Latin supplement 和 latin-ext WOFF2，合起来保留完整字符覆盖；不使用可变字重或浏览器合成粗体。core 与 supplement 保留像素对齐指令，字形轮廓、字宽、字距及垂直度量不变。预加载两档 core 文件并设置高请求优先级，使用 `font-display: block`，保留字体许可证。core 和 supplement 从 `src/assets/fonts/` 构建为带内容哈希的资源，避免更新后复用旧字体。补充字符、latin-ext 与 Noto Sans SC 仅按需加载；首页与 404 当前文字只下载两份 core，共 28,740 bytes。

加载期间用本机 Arial / Arial Bold 占位，通过字体度量校准减少换行和位置变化，不增加字体下载，也不改变最终使用的 Nunito。普通文字、紧凑标签和等宽数字分别校准，避免年份栏加载后改变宽度、挤动校徽或使校名临时换行。

| 后备用途 | size-adjust | ascent-override | descent-override |
| --- | --- | --- | --- |
| `Nunito Fallback` 常规文字 400 | 101.02% | 100.08% | 34.94% |
| `Nunito Fallback` 粗体文字 700 | 97.77% | 103.41% | 36.10% |
| `Nunito UI Fallback` 学校及导航标签 700 | 96.28% | 105% | 36.66% |
| `Nunito Numeric Fallback` 年份及导航编号 700 | 108.21% | 93.43% | 32.62% |

所有后备的 `line-gap-override` 为 `0%`。这些是临时字体的度量参数，不是新的界面字号或行高；没有 Arial 时继续使用其余后备字体。最终排版始终优先使用同一套 Nunito。

背景固定白色，使用 `color-scheme: only light` 和浅色页面元数据，不随系统外观切换。主内容、侧栏和图文条目的文字区明确使用不透明白色背景，不添加文字层 transform、强制 GPU 图层或透明度动画。

## 文字颜色

常规文字及其悬停状态共用两种颜色；背景、边框、阴影、图片内容不计入字体色。

| 色值 | 变量 | 用途 |
| --- | --- | --- |
| `#243B53` 蓝黑 | `--ink`；`--body` / `--muted` 引用它 | 姓名、所有标题、正文、学校、年份、作者、学位专业、项目类别、普通导航、资源按钮、社交图标 |
| `#2867A5` 蓝色 | `--accent` | 当前导航、404 返回链接及其悬停状态、资源按钮和社交图标悬停 |
| `#FFFFFF` | — | Skip to content 键盘焦点文字，仅无障碍入口的例外 |

普通 strong 继承所在文字的颜色，通过字重体现层级。论文/项目标题均为无链接的蓝黑文字；About Me 学校名称不单独设色或加链接。外部文本链接通过 arXiv / Code / Demo 及社交入口访问，项目图片也可打开对应仓库。

边框与教育分隔线为 `#DCE5EE`，资源按钮边框为 `#7C8C9B`，图片阴影为 `#B0B0B0`，选择背景为 `#DAEDF7`。资源按钮无填充。校徽保留官网原色。favicon 保持 `#3399CC` 实心圆润闪电、透明背景及小尺寸轮廓补偿，使用共享 SVG、PNG 和 ICO。

## 字号、行高与字重

六档字号，五档整数行高；各屏幕沿用同一套数值，依靠换行与布局适配。

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| arXiv / Code / Demo 资源按钮 | 14px | 24px | 400 |
| 学位专业、其他作者、项目类别、404 返回链接 | 16px | 28px | 400 |
| 全部导航、时间轴年份、作者中的本人姓名 | 16px | 28px | 700 |
| About Me、研究兴趣、404 辅助文字、Skip to content | 18px | 32px | 400 |
| 学校名称 | 18px | 32px | 700 |
| 论文与项目标题 | 18px | 28px | 700 |
| (Dawei HUANG) | 22px | 28px | 700 |
| 栏目标题 | 26px | 36px | 700 |
| David、404 主标题 | 32px | 40px | 700 |

字号依次由 `--text-button`、`--text-meta`、`--text-body`、`--text-subheading`、`--text-heading`、`--text-title` 控制。行高使用 `--line-compact: 24px`、`--line-meta: 28px`、`--line-body: 32px`、`--line-heading: 36px`、`--line-title: 40px`，不要为单个组件新增相近倍数或小数档位。

研究兴趣不另加条目 margin，连续单行条目的基线间距为 32px，换行后仍使用同一行高。圆点使用直径 6px 的 CSS 圆形，距首行行框顶部 13px，与首行垂直居中；圆点右边缘至文字容器为 24px。列表左侧内边距 20px，文字从左侧 50px 起排，换行沿文字左边缘对齐。保留 `ul` / `li` 结构及显式 `role="list"`，不依赖浏览器默认圆点间距。无额外字距设置。行高包含字形本身，不等于字形之间的纯空白。

作者名单保留原顺序及本人姓名加粗。桌面可向右侧留白延伸，空间不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 内容间距

主要内容留白采用 4px 倍数，按细部、组内、条目、板块分层。以下是 CSS 布局边界的距离，不含字形内部留白和图片阴影。

元素间距通过共享变量控制：`--control-gap: 16px` 用于并排资源按钮、导航竖线内侧至编号及编号至文字；`--item-gap: 24px` 用于社交图标外框、Education 各列、研究兴趣圆点与文字；`--media-gap: 32px` 用于论文／项目图片外框与文字。字号、行高、控件内部留白、段落及板块间距按各自角色控制。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Education → Research Interests → Publications，相邻板块 | 96px | 48px | 48px |
| Publications → Projects | 96px | 48px | 48px |
| 栏目标题至首项内容 | 24px | 24px | 24px |
| 相邻论文或项目条目 | 48px | 48px | 40px |
| 图片外框至文字区域 | 横向 32px | 横向 32px | 上下 32px |
| 普通段落之间 | 24px | 24px | 24px |
| 条目标题至作者或类别 | 8px | 8px | 8px |
| 作者或类别行框至资源按钮上边缘 | 16px | 16px | 16px |

全部相邻板块共用 `--section-gap`：桌面为 96px，单栏为 48px，均大于锚点顶部留白，保证点击导航后上一板块及阴影退出视口。板块末项无底部 margin，条目首项无额外上边距。标题下方共用 `--heading-content-gap`，段落共用 `--paragraph-gap`。

图文在桌面/平板垂直居中，手机为图片在上、文字在下。论文与项目图片没有外加标签或裁剪。图片外框与标题区域的间距使用 grid gap，不叠加图片 margin；图片内部图形自带的留白不计入间距。

条目内按字形的视觉留白对齐：标题至作者/类别使用 8px 行框间距，作者/类别至按钮边缘使用 16px。两行文字的字形外都有行高留白，按钮边框不带这部分留白，因此使用不同的 CSS 间距，使“标题字形下沿→下一行字形上沿”与“下一行字形下沿→按钮上沿”看起来接近。

桌面显示 01–05 编号导航，编号和文字分别沿同一左边缘对齐；全部状态为 16px / 28px / 700。最小点击高度 44px，项间距 4px。导航容器左右内边距 16px，下方 margin 24px；链接上下内边距 6px，左侧 16px；竖线内侧至编号 16px，编号至文字 16px。当前项使用蓝色文字与左侧 2px 竖线。单栏屏幕隐藏编号，链接左右无内边距，当前项改用底部 2px 横线；其他项使用透明边框，切换时不位移。

社交图标外框为 24×24px，外框之间相隔 24px；点击区域保持 40×40px。每个图标在点击区域左右各留 8px，因此点击区域间距使用 `calc(var(--item-gap) - 16px)`，实际为 8px。SVG 路径内部留白不计入外框间距，两个可见轮廓之间约为 26px。

资源按钮字体 14px、行高 24px、上下内边距 0px / 左右 8px、边框 1px，总高度 26px。按钮使用 `border-radius: 13px`，圆角半径为高度的一半，形成上下平直、两端半圆的胶囊轮廓；文字水平和垂直居中，按钮间距 16px。宽度按标签内容自动确定；仅使用原生 CSS，不依赖脚本或实验性角形属性。整数高度由既有 24px 行高与上下边框组成，不新增行高档位。

| 图片外边距 | 0 | 上下 0、水平居中 |

| 项目图片内边距 | 0 | 0 |

桌面外框宽 960px：左侧内边距 48px、侧栏 232px、列间距 32px、正文 648px。头像、姓名、社交图标和导航随侧栏整体定位；侧栏 sticky，窗口较矮时可独立滚动。≤1000px 为居中单栏，最大宽度 720px，左右内边距 24px；≤520px 左右内边距 20px。单栏个人资料区底部留 32px，经 1px 分隔线后，主内容区顶部再留 32px。

首页桌面主内容顶部内边距与锚点偏移共用 `--anchor-offset: 76px`。结合 Nunito 标题行框内约 8px 的字形留白，各栏目标题的可见上沿与距窗口顶部 84px 的头像图片对齐。单栏屏幕的锚点偏移为 32px，头像随页面滚动。

404 主内容区顶部内边距为桌面 64px、单栏 32px，使用独立于首页的顶部布局。404 内容区额外向下留 32px；提示行、主标题、说明、返回链接依次间隔 24px。返回链接单独成块，使间距不受行内基线影响。

键盘 Skip to content 入口获得焦点时出现在顶部 16px、左侧 20px，内边距上下 8px / 左右 16px。链接焦点轮廓为 2px、外偏移 4px。页面仅在 html 的 scroll-padding-top 设置 `--anchor-offset`，不叠加栏目 scroll-margin。`--content-bottom` 引用同一个 `--anchor-offset`，使最后一个项目外框下方的留白等于首页 About Me 上方的布局留白。各板块按实际内容高度展开，不设置整屏最小高度。接近页尾的锚点受浏览器实际滚动范围限制，高窗口下以页尾位置为准。

## 导航与加载

使用浏览器原生滚动，锚点直接定位，不添加平滑跳转或页面淡入淡出。点击、键盘激活、直接访问 hash 和历史返回均可定位；当前项随实际位置变化。IntersectionObserver 在标题越过定位线或最后一项到达页尾留白线时触发更新，布局或字体就绪后校准观察范围；不在每次滚动时执行页面脚本。滚动到页底时高亮 Projects，向上离开后恢复按栏目边界判断。尊重减少动态效果偏好，无 JavaScript 时导航与内容仍可使用。

论文及 PPT-Agent 原图保存在 `src/assets/`，构建时生成 240 / 480 / 720px 宽、质量参数 95 的 WebP，通过 srcset 和 sizes 按显示尺寸及像素密度选择。图片保持原比例、完整内容和延迟加载，不改变外框尺寸。SVG、头像和校徽保持各自原始资源。404 返回箭头使用内联 SVG，与文字居中对齐，图标 16px、图文间距 8px。

## 验收

运行 check、build、test；检查电脑、手机、两种浏览器颜色偏好。验证五个导航目标、当前项跟踪、键盘焦点、前进后退、页尾跳转、作者局部滚动、图片和无整页横向溢出。核对六档字号、五档整数行高、两种常规文字颜色、两档字重与 Education 层级。

验证所有栏目在各断点的最终位置，尤其是 Research Interests 上方不露出校徽、页尾留白与顶部一致、页底及向上离开页底时导航高亮正确。锚点在滚动空间允许时对齐统一顶部偏移，接近页尾时允许原生滚动范围限制。检查快速重复点击、键盘和历史返回，确认高亮与实际位置一致。性能测试注明测试设备、模拟条件和测量口径，不把实验室成绩作为所有访客的保证。
