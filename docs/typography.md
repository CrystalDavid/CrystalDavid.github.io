# 字体颜色与字号清单

更新日期：2026-10-16。当前版本已恢复原蓝色配色，固定浅色背景，覆盖首页、五篇文章和 404 页面。

## 统计口径

使用 Microsoft Edge 的 `getComputedStyle` 统计实际显示文本，包括滚动后可见正文；排除隐藏元素、图片内文字、favicon 和浏览器界面。浏览器设置为浅色或深色时，网站使用同一组浅色配色。下面分别列出默认文字色与悬停颜色。

## 实际文字颜色

- 全站默认文字色：6 种（缩略图标签已删除）。
- 加上链接悬停色：共 7 种；再计入键盘聚焦时的跳过导航白字，共 8 种。
- 网站固定浅色，没有另一套深色配色。

| 用途 | 固定浅色 |
| --- | --- |
| 简介、研究兴趣、学校、作者列表 | #595959 |
| 姓名、栏目/文章标题、作者姓名强调、资源按钮 | #043361 |
| 普通链接、论文/项目标题链接、当前目录项 | #3399cc |
| 投稿状态/项目类型、文章正文 | #444444 |
| 项目说明、代码正文 | #333333 |
| 阅读时间、文章状态说明、代码工具栏 | #777777 |
| 键盘聚焦时的跳过导航文字（非常驻） | #ffffff |
| 普通链接悬停 | #006699 |

标题、链接、图标、边框、选择高亮和 favicon 已恢复灰色调整前的配色；图片保留原色。图片上的名称标签及论文条目的短说明已经删除。灰色版本新增的链接下划线已撤回。白色背景与蓝色文字不随浏览器外观切换。

CSS 保留通用 `strong` 的 #222222，但当前实际 `strong` 均被作者姓名样式覆盖，因此不计入实际数量。若连同未使用的通用色和悬停色一起数 CSS 定义，共 9 种文字色。

## 实际字号：15 种

| 字号 | 实际用途 |
| --- | --- |
| 12px | PDF / Code / Notes 等胶囊按钮、代码工具栏、手机代码正文 |
| 13px | 桌面文章目录、阅读时间、文章状态、桌面代码正文 |
| 14px | 作者/投稿信息、文章来源/返回链接、手机左栏专业 |
| 15px | 桌面左栏专业、项目说明 |
| 16px | 首页简介/研究兴趣/学校、桌面条目标题、手机文章正文 |
| 17px | 文章摘要与桌面正文、章节序号、手机条目标题 |
| 20px | 文章内三级标题 |
| 22px | 文章页左栏的 (Dawei HUANG) |
| 23px | 首页的 (Dawei HUANG)、手机文章二级标题 |
| 25px | 文章页左栏 David、桌面文章二级标题 |
| 25.12px | 首页栏目标题 |
| 27px | 手机首页 David |
| 28px | 桌面首页 David、404 标题 |
| 29px | 手机文章主标题 |
| 32px | 桌面文章主标题 |

首页桌面为 7 种：12、14、15、16、23、25.12、28px；首页手机为 8 种：12、14、15、16、17、23、25.12、27px。全站数量包含响应式变体，并非单个页面同时显示 15 种字号。favicon SVG 内的 D 是 49 个 SVG 用户单位，不是页面 CSS 字号，不计入。

主字体为 Nunito；代码块为 Ubuntu Mono；Noto Sans SC 等为后备字体。既有字体与字号保持不变。流程图 SVG 内的文字属于图片内容，不计入页面 CSS 字号或文字颜色。

## 后续建议（尚未实施）

15 种字号偏细碎，尤其 25 与 25.12、27 与 28px 区别很小。后续可以统一为约 6–7 个语义字号。当前保留已有字号与用户确认的蓝色配色。
