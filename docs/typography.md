# 全站字体、颜色与间距清单

更新日期：2026-10-17。对象为固定浅色、蓝色主题的首页、三篇公开文章和 404 页面。GRA-Flow、RECAST 只保留首页列表。

## 实测口径

用 Microsoft Edge 的 getComputedStyle 检查实际显示的 HTML 文字，含滚动后的文章正文；排除隐藏内容、图片/SVG 内文字、favicon 和浏览器界面。覆盖 320、390、768、1440px；浏览器浅/深色偏好使用同一套白色背景配色。默认态与悬停/键盘焦点态分开统计。

## 字体

主字体为本地 Nunito，代码使用 Ubuntu Mono，非英文后备为 Noto Sans SC 与系统中文字体。

## 文字颜色：常驻 6 种，含交互共 8 种

| 色值 | 当前用途 |
| --- | --- |
| #043361 | 姓名、栏目/文章标题、作者姓名强调、资源按钮；社交图标也用此色 |
| #3399cc | 普通链接、论文/项目标题、当前目录项 |
| #595959 | 简介、研究兴趣、学校/专业、作者列表、文章摘要 |
| #444444 | 投稿状态、项目类型、文章正文 |
| #333333 | 代码正文 |
| #777777 | 阅读时间、文章状态、代码工具栏 |
| #006699 | 普通链接悬停（交互态） |
| #ffffff | 键盘聚焦时的跳过导航文字（交互态） |

首页默认出现前四种，文章页额外使用 #333333 和 #777777，因此全站默认六种。白色背景、边框 #e5e5e5 / #7c8c9b、选择背景 #daedf7 不计作字体色。CSS 通用 strong 仍定义 #222222，但当前实际都被作者姓名样式覆盖，不计入实际使用数量；连同未使用定义共九种。

## 关键间距与宽度

| 位置 | 桌面 | 手机/单栏 |
| --- | --- | --- |
| 首页板块之间 | 48px | 40px（宽度 ≤1000px） |
| 简介/研究兴趣/生活标题至正文 | 18px | 18px |
| 论文/项目栏目标题至第一条 | 24px | 24px |
| 相邻论文或项目条目 | 42px | 32px（宽度 ≤520px） |
| 配图与文字 | 横向 28px | 上下 18px（宽度 ≤520px） |
| 文章章节之间 | 44px | 40px（宽度 ≤1000px） |
| 段落之间 | 首页 20px、文章 18px | 相同；板块末项底部为 0 |
| 左侧个人栏与右侧主栏 | 78px | 单栏，无横向列间距 |
| 内容总宽度 | 960px（232 + 78 + 650） | 最大 720px，含左右内边距 |
| 单栏左右内边距 | — | 25px；宽度 ≤520px 为 20px |
| 页面顶部留白 | 64px | 个人栏 50px；宽度 ≤520px 为 28px |

原首页板块间距实测：桌面 20 / 28 / 42 / 42px，手机 20 / 28 / 32 / 32px；现分别统一为 48px 和 40px。使用 flow-root 与末项外边距归零，避免子元素外边距改变板块间的实际留白。

论文作者和文章作者固定为 15px 单行文字，保留原顺序和本人姓名加粗。桌面允许名单超出文字列、向右侧留白延伸；不足以容纳完整名单的屏幕仅让作者行横向滚动，不折行、不省略、不缩小字号。移除项目说明后，首页默认文字色为四种，全站颜色和字号总数不变。

## 验证

正文放大时，五个公开页面检查 30 个视口/浏览器外观组合，验证字号、行高、板块间距和颜色。随后作者单行调整验证首页与 ProME 文章页在 320/390/768/1001/1440/1920px 的 12 种布局；窄屏作者行可横向滑动，整页不溢出，宽屏名单完整向右延伸。两个项目首页说明已移除，文章内容仍在；两篇暂不公开稿件继续只展示列表。详见 docs/verification.md。
