# 网站视觉规范

本文件是首页及 404 页面字体、颜色、字号、行高、间距和响应式布局的唯一规范。实现位于 `src/styles/global.css`；修改任意一方时同步另一方。`AGENTS.md` 和 `README.md` 仅提供入口。

## 字体与主题

全站使用本地 Nunito，仅使用 400 和 700 两档字重。About Me 正文、研究兴趣、学位专业、其他作者、项目类别、资源按钮与 404 辅助文字使用 400；姓名、栏目标题、论文/项目标题、学校、本人署名、时间轴年份、全部导航使用 700。切换当前导航项不改变字重，避免文字宽度变化。

保留字体文件、许可证、Nunito latin 预加载及 `font-display: block`，保证字体与排版稳定。缺失字形使用现有 Noto Sans SC 与系统字体后备，不预加载后备字体。

背景固定白色，使用 `color-scheme: only light` 和浅色页面元数据，不随系统外观切换。

## 文字颜色

常规文字及其悬停状态共用两种颜色；背景、边框、阴影、图片内容不计入字体色。

| 色值 | 变量 | 用途 |
| --- | --- | --- |
| `#243B53` 蓝黑 | `--ink`；`--body` / `--muted` 引用它 | 姓名、所有标题、正文、学校、年份、作者、学位专业、项目类别、普通导航、资源按钮、社交图标 |
| `#2867A5` 蓝色 | `--accent` | 当前导航、404 返回链接及其悬停状态、资源按钮和社交图标悬停 |
| `#FFFFFF` | — | Skip to content 键盘焦点文字，仅无障碍入口的例外 |

普通 strong 继承所在文字的颜色，通过字重体现层级。论文/项目标题均为无链接的蓝黑文字；About Me 学校名称不单独设色或加链接。外部文本链接通过 arXiv / Code / Demo 及社交入口访问，项目图片也可打开对应仓库。

边框与教育分隔线为 `#DCE5EE`，资源按钮边框为 `#7C8C9B`，图片阴影为 `#B0B0B0`，选择背景为 `#DAEDF7`。资源按钮无填充；备用导航按钮普通态白底，悬停和当前项使用 `#F1F6FB` 浅蓝背景及蓝色边框。校徽保留官网原色。favicon 保持 `#3399CC` 实心圆润闪电、透明背景及小尺寸轮廓补偿，使用共享 SVG、PNG 和 ICO。

## 字号、行高与字重

六档字号，五档整数行高；各屏幕沿用同一套数值，依靠换行与布局适配。

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| arXiv / Code / Demo 资源按钮 | 14px | 24px | 400 |
| 学位专业、其他作者、项目类别、经典布局年份、404 返回链接 | 16px | 28px | 400 |
| 全部导航、时间轴年份、作者中的本人姓名 | 16px | 28px | 700 |
| About Me、研究兴趣、404 辅助文字、Skip to content | 18px | 32px | 400 |
| 学校名称 | 18px | 32px | 700 |
| 论文与项目标题 | 18px | 28px | 700 |
| (Dawei HUANG) | 22px | 28px | 700 |
| 栏目标题 | 26px | 36px | 700 |
| David、404 主标题 | 32px | 40px | 700 |

字号依次由 `--text-button`、`--text-meta`、`--text-body`、`--text-subheading`、`--text-heading`、`--text-title` 控制。行高使用 `--line-compact: 24px`、`--line-meta: 28px`、`--line-body: 32px`、`--line-heading: 36px`、`--line-title: 40px`，不要为单个组件新增相近倍数或小数档位。

研究兴趣不另加条目 margin，连续单行条目的基线间距为 32px，换行后仍使用同一行高。无额外字距设置。行高包含字形本身，不等于字形之间的纯空白。

作者名单保留原顺序及本人姓名加粗。桌面可向右侧留白延伸，空间不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 内容间距

主要内容留白采用 4px 倍数，按细部、组内、条目、板块分层。以下是 CSS 布局边界的距离，不含字形内部留白和图片阴影。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Education → Research Interests → Publications，相邻板块 | 56px | 48px | 48px |
| Publications → Projects | 64px | 56px | 48px |
| 栏目标题至首项内容 | 24px | 24px | 24px |
| 相邻论文或项目条目 | 48px | 48px | 40px |
| 图片外框至文字区域 | 横向 32px | 横向 32px | 上下 24px |
| 普通段落之间 | 24px | 24px | 24px |
| 条目标题至作者或类别 | 8px | 8px | 8px |
| 作者或类别至资源按钮行 | 8px | 8px | 8px |

板块基础间距使用 `--section-gap`，论文板块之后的 `--figure-section-gap` 在桌面/平板多留 8px 补偿图片阴影，使视觉留白接近纯文字板块。手机条目以文字或按钮结尾，不加补偿。板块末项无底部 margin，条目首项无额外上边距。标题下方共用 `--heading-content-gap`，段落共用 `--paragraph-gap`。

图文在桌面/平板垂直居中，手机为图片在上、文字在下。论文与项目图片没有外加标签或裁剪。图片外框与标题区域的间距使用 grid gap，不叠加图片 margin；图片内部图形自带的留白不计入间距。

## 图片与页面布局

| 图片细部 | 桌面 / 平板 | 手机 |
| --- | --- | --- |
| 论文与项目图片外框 | 192×128px | 240×160px |
| 图片外边距 | 0 | 上下 0、水平居中 |
| 论文图片内边距 | 8px | 8px |
| 项目图片内边距 | 0 | 0 |
| 图片圆角 | 8px | 8px |
| 阴影 | 水平 3px、垂直 3px、模糊 6px | 同左 |

桌面总宽 960px：侧栏 232px、列间距 80px、正文 648px。侧栏 sticky，窗口较矮时可独立滚动。≤1000px 为单栏，最大宽度 720px，左右内边距 24px；≤520px 左右内边距 20px。单栏个人资料区底部留 32px，经 1px 分隔线后，主内容区顶部再留 32px。

404 内容区额外向下留 32px；提示行、主标题、说明、返回链接依次间隔 24px。返回链接单独成块，使间距不受行内基线影响。

键盘 Skip to content 入口获得焦点时出现在顶部 16px、左侧 20px，内边距上下 8px / 左右 16px。链接焦点轮廓为 2px、外偏移 4px。页面锚点使用 html 顶部滚动留白 32px 与栏目 scroll-margin 32px，常规定位总留白为 64px；页尾受浏览器可滚动范围限制。

## 可选样式与交互

`src/data/presentation.ts` 独立控制两处样式，当前为 `education: 'timeline'`、`navigation: 'classic'`。Education 可选 `timeline` / `classic`，导航可选 `classic` / `buttons`。两套教育结构保存在 `src/components/Education.astro`，导航样式按类名隔离保存在全局 CSS。切换在构建时完成，访客只收到选中的结构，没有运行时样式开关。

使用浏览器原生锚点与滚动。导航点击、键盘激活及直接访问 hash 均可定位；滚动更新当前项，点击页尾栏目后保持所选项，手动滚动恢复跟踪。减少动态效果偏好关闭平滑滚动和页面过渡。无 JavaScript 时导航与内容仍可使用。

## 验收

运行 check、build、test；检查电脑、手机、两种浏览器颜色偏好。验证五个导航目标、当前项跟踪、键盘焦点、前进后退、页尾跳转、作者局部滚动、图片和无整页横向溢出。核对六档字号、五档整数行高、两种常规文字颜色、两档字重与 Education 层级。

修改共用视觉规则后，在验证副本中检查经典 Education、按钮导航及其独立组合，发布前恢复默认配置。当前说明只描述生效规则，不记录历史样式数值。

本地查看与检查命令见 [README](../README.md)，内容依据见 [研究资料来源](research-sources.md)。
