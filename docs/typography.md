# 网站视觉规范

本文件是首页及 404 页面字体、颜色、字号、行高、间距和响应式布局的唯一规范。实现位于 `src/styles/global.css`；修改任意一方时同步另一方。`AGENTS.md` 和 `README.md` 仅提供入口。

## 字体与主题

全站使用本地 Nunito，包括正文、姓名、学校、导航、作者及按钮。普通文字使用 400 字重，标题、学校、本人姓名和当前导航使用 700 字重。保留现有字体文件、许可证、Nunito latin 预加载及 `font-display: block`，优先保证字体统一和排版稳定。缺失字形使用现有 Noto Sans SC 与系统字体后备，不预加载后备字体。

背景固定白色，使用 `color-scheme: only light` 和浅色页面元数据。布局、文字及资源均不随系统外观切换。

## 文字颜色

常驻文字仅使用三种颜色；背景、边框、阴影、图片内容和选择高亮不计入字体色。

| 色值 | 变量 | 用途 |
| --- | --- | --- |
| `#16324F` | `--ink` | 姓名、栏目标题、学校、无外链的论文标题、本人署名、资源按钮、社交图标 |
| `#243B53` | `--secondary`；`--body` / `--muted` 引用它 | 正文、学位专业、年份、作者、项目类别、普通导航 |
| `#2867A5` | `--accent` | 外链文字、带外链的论文/项目标题、当前导航 |
| `#174878` | `--accent-hover` | 普通链接悬停，仅交互态 |
| `#FFFFFF` | — | Skip to content 键盘焦点文字，仅交互态 |

资源按钮和社交图标悬停使用 `--accent`。普通 strong 继承所在文字的颜色。文字与白色背景的对比度至少达到 4.5:1。

边框为 `#DCE5EE`，按钮边框为 `#7C8C9B`，图片阴影为 `#B0B0B0`，选择背景为 `#DAEDF7`。按钮无填充。favicon 保持 `#3399CC` 实心圆润闪电、透明背景；共享 SVG、PNG 与 ICO 资源，保留小尺寸轮廓补偿。

## 字号与行高

| 字号 | 变量 | 用途 | 行高 |
| --- | --- | --- | --- |
| 14px | `--text-button` | arXiv / Code / Demo 胶囊按钮 | 1.5 / 21px |
| 16px | `--text-meta` | 学位专业、年份、作者、项目类别 | `--line-meta` = 1.65 / 26.4px |
| 16px | `--text-meta` | 左侧/移动端导航、404 返回链接 | 1.7 / 27.2px |
| 18px | `--text-body` | 正文、学校、404 正文 | 1.7 / 30.6px |
| 18px | `--text-body` | 论文与项目标题 | 1.5 / 27px |
| 22px | `--text-subheading` | (Dawei HUANG) | 1.2 / 26.4px |
| 26px | `--text-heading` | 栏目标题 | `--line-heading` = 1.3 / 33.8px |
| 32px | `--text-title` | David / 404 标题 | 1.2 / 38.4px；404 为 1.4 / 44.8px |

Education 层级为：26px 栏目标题，18px 海军蓝加粗学校，16px 蓝黑色学位专业与年份。桌面学校与年份同一行，学位专业占下一行；手机按学校、学位专业、年份排列。不要把这些信息全部设成同一字号。

作者名单保留原顺序与本人姓名加粗。桌面可向右侧留白延伸，空间不足时仅作者行横向滚动，不折行、不省略、不缩小字号。

## 间距

间距按 CSS 布局边界计算，不含字形内部留白和图片阴影。相邻垂直 margin 按折叠规则计算。

| 位置 | 桌面 >1000px | 平板 521–1000px | 手机 ≤520px |
| --- | --- | --- | --- |
| About Me → Education → Research Interests → Publications，相邻板块 | 48px | 40px | 40px |
| Publications → Projects | 56px | 48px | 40px |
| 栏目标题至首项内容 | 18px | 18px | 18px |
| 相邻论文或项目条目 | 42px | 42px | 32px |
| 条目图片与文字 | 横向 28px | 横向 28px | 上下 18px |

板块基础间距使用 `--section-gap`；论文板块后的 `--figure-section-gap` 在桌面/平板增加 8px 阴影补偿。手机条目以文字或按钮结尾，不加补偿。板块末项无底部外边距，条目首项无额外上边距。标题下方共用 `--heading-content-gap`。

| 细部 | 值 |
| --- | --- |
| 普通段落之间 | `--paragraph-gap` = 18px |
| Education 列间距 / 行间距 | 24px / 4px |
| 条目标题至作者或类别 | 4px |
| 资源按钮行上方 / 按钮间距 | 8px / 5px |
| 按钮内边距 | 上下 2px、左右 10px；圆角 999px |
| 社交图标间距 / 点击区域 / 图标 | 8px / 38×38px / 24×24px |
| 桌面导航上方 / 下方 / 左右内边距 | 28px / 24px / 18px |
| 桌面导航项间距 / 内边距 / 序号间距 | 4px / 上下 6px、左 12px / 12px |
| 移动布局导航上方 / 行列间距 / 项内边距 | 20px / 4px 18px / 上下 6px |

桌面导航当前项使用蓝色文字、700 字重与左侧 2px 竖线；移动布局使用底部 2px 横线。其他项保留透明边框，状态切换不挤动布局。小屏幕不显示装饰序号，导航自然换行。

## 布局与交互

桌面宽度 960px：侧栏 232px、列间距 78px、正文 650px。侧栏 sticky 并可在窗口较矮时独立滚动。≤1000px 为单栏，最大宽度 720px、左右内边距 25px；≤520px 左右内边距 20px。顶部留白依次为 64px、50px、28px。

正文底部内边距 40px。单栏个人资料区底部 25px，内容区顶部分隔线后留 25px。姓名下方 margin 为桌面 22px、单栏 15px，副行上方 4px；社交图标行上方为桌面 24px、单栏 15px。头像外框底部 margin 为桌面 10px、单栏 8px。

使用浏览器原生锚点与滚动；导航点击、键盘激活及直接打开带 hash 的链接均可定位栏目。滚动时更新当前项，点击页尾栏目后保持所选项，继续手动滚动时恢复跟踪。减少动态效果偏好下关闭平滑滚动和页面过渡。无 JavaScript 时，导航和全部内容仍可使用。

## 验收

运行 check、build、test；检查首页与 404 在电脑、手机及两种浏览器颜色偏好下的表现。验证五个导航目标、当前项跟踪、键盘焦点、浏览器前进后退、页尾跳转、作者局部滚动、图片和无整页横向溢出。核对六档字号、三种常驻文字颜色、两档字重和 Education 层级。

本地查看与检查命令见 [README](../README.md)，内容依据见 [研究资料来源](research-sources.md)。
