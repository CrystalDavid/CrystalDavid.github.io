# David's Personal Website

David 的个人网站仓库。网站目前已下架，正在准备更新内容。

旧版完整源码、静态资源和提交历史已保存在公开仓库 [Portfolio](https://github.com/CrystalDavid/Portfolio)，可用于参考首屏入场、滚动叙事、视差、双语排版和响应式设计。

## 预览旧版

需要 Node.js 22.13+ 和 npm：

```bash
git clone https://github.com/CrystalDavid/Portfolio.git
cd Portfolio
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。动效入口和使用说明见 [旧版项目 README](https://github.com/CrystalDavid/Portfolio#readme)。
